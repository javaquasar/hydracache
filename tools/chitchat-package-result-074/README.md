the real Cargo archive, both complete library catalogs,83 actual passing cases,
the first5-second timeout and complete policy under both package identities.

the package archive and whole checked RustSec snapshot. Build caches and private

semantics; `restore DIGEST target/NEW` exports only the exact package source,
refuses existing/outside destinations, and never builds or runs it.

success cannot authorize actual publication, Root adoption, MTU/resource/CPU/RSS,
upstream integration-target runtime or release admission. Preserve all original
checks, first refusals, deadlines and thresholds.
