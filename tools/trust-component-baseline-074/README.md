# Pure trust component CString baseline

Freeze `CString::new(name)` and the complete private trust `child` body before
any storage replacement. Six fixed component names are shared by worker,
controller, held-runtime and OIDC readers. Generic empty, Unicode, slash/dot and
large names remain part of the pure contract; CString conversion is not path
validation or proof that an OS open succeeds.

`check.ps1 -Lane host|194|188 -Cohort <new-name>` refuses existing logs. Host
runs 28 source canaries and affected all-target check/strict all-feature lint.
GNU/MSRV each run five new pure controls, four existing context-stack controls,
five unchanged context baseline controls and two counter controls, then affected
check/lint. Controls invoke no File, openat, Probe, clock or live owner; ordinary
user WSL supplies only Rust build/unit execution. No ignored/manual test runs.

Twenty-one valid name shapes and four embedded-NUL shapes each have 256
constructions. The complete-body model substitutes only openat, last-error and
File construction, checking one callback, exact terminated bytes/parent/flags,
NUL priority, negative descriptor handling and no EINTR retry. A seeded 512-case
schedule control and independent owned values complete the contract. These are
synthetic operands, not filesystem/race integration tests or actual ownership.

Both first Linux compiles refuse a nonexistent `NulError::as_bytes` method.
Retain those logs and the original test. The corrected cohort consumes the error
with `into_vec()` to inspect its original payload; no clone/allocation or runtime
change is introduced by that test-only repair. Never replace a first outcome.

The packet holds both cohorts, initial/final source and method snapshots, plus
format/doc/registry/local performance checks. After the exact source commit,

`review.ps1 -Mode Review` checks it offline, including seven prior raw seals and
303 members. Do not change their frozen source-pinned historical reviewers.

This baseline implements no runtime candidate or timing improvement. Requested
bytes are Rust requests, not RSS/CPU/retention or preparation headroom. Original

clock/service/server/Actions/install/supervisor/product operation or readiness
promotion is part of this method. A later candidate needs separate evidence.
