# Declined C1 prerequisite; no borrowed MTU implementation

This is a source-only controlled experiment for the separately approved local
MTU work. B0 delegates to the original stateless compressor; C1 changes only the
private helper to retain a lazy per-writer context. Actual Windows differential
controls and GNU native observations are retained. C1 is declined for extra
owned C-live bytes at append checkpoints, despite fewer total allocations.
The combined MTU algorithm and CPU/rescue cohorts are not implemented/dispatched.

`recipe.py` constructs a failing baseline before materializing C1. `run.py` uses
the original Windows Job; `native.py` uses Job/subreaper bounds and private native
directories. Commands/output labels refuse reuse. The final native method keeps
independent per-input target directories, fresh compilation, runtime source and
context tags, exact source/registry/object/image/catalog guards and all original
windows/floors. `parallel_source.py` orchestrates independent CI source reads
through the unchanged qualified openat2 helper; production validation is untouched.
