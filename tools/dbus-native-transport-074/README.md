# Native zbus 6 manual-transport continuation

Separate local source candidate after the joined callers' paired 64-case gate.
The manual test transport delegates to zbus 6's actual registered Unix backend,
using the same runtime selection/UnixOps as its connection builder. An explicitly
nondefault hc074-unix-fixture feature exposes only that source-internal factory
to bounded tests. Production default features and original fixed manager/frame/
kernel/authority callers stay unchanged. This is a locally modified backport,
with updated unsigned provenance, not pristine upstream or an admitted release.

Reader/writer wrappers retain wire prefix/partial-write capture and capability
faults. The original atomic truncation guard remains: it uses a cloned socket in
the same private fixture, never a payload/writer FD or production owner. The
ordinary path and peer credentials now come from the actual zbus 6 backend.
The retained DTO control becomes single-backend metadata transfer; it still
preserves missing/empty fields, kernel FD identity/CLOEXEC and closing both slots.
No tests, old bounds or source predicates are removed.

The old zbus 5 dev requirement is removed from this new temporary manifest.
Its inherited lock is deliberately not accepted: first perform one offline
generate-lockfile under the original owned CI envelope. The pure semantic lock
review allows no new package/checksum or changed retained edge; only the old
root test edge and packages no longer reachable may disappear. It rejects old
zbus remaining anywhere in the actual resolved candidate graph. Retained baseline
source/lock/archive files are provenance, not the selected workspace graph.

the fixed caller, then `resolve_run.py`. The resolver may change only the native
fd/Cargo.lock; all prepared Windows inputs/protected roots and remaining native
sources must stay exact. The outer/native receipts explicitly distinguish that
allowed lock mutation from unchanged source; no false source_unchanged pass.
1200/1100-second origins, 4 GiB floors and five-second polling/retirement stay.

Metadata resolution executes no build script, test, manager, service, clock or
server workload. Compiler/MSRV, all 64 prior cases, real private-bus transport/
FD/fault checks, new source-package reconstruction and full policy/root/product
