This offline, nonroot GNU continuation projects the exact existing supervisor
ReplyState module into the held zbus 6 / Rust 1.88 candidate. `run.py` pins the
five original files and packet, preserves every assertion in the selected 25-case
corpus, and records each spelling adaptation. Only fixture builder-result unwraps
are removed: zbus 6 records conversion errors until build. The execution module
changes only the wire namespace and flag-bit spelling. No transport/live owner
predicate is stubbed or represented by the copied protocol size constant.

The parent owner is hash-bound. Its floors, absolute session origin, Windows Job,
Linux subreaper/pidfd retirement, complete catalog and strict lint remain intact.
The corrected candidate includes 42 predecessor cases plus 25 original cases.
`native_alias_fixed.py` is the exclusive corrected worker context. `native.py`
also retains the first-attempt entry; its already-used output is never overwritten.
Commands fail if outputs exist. No system bus, service, clock, server or product
workload is addressed. This gate is not original-start/all-writer admission.

Preparation and execution: `python -B tools/dbus-reply-state-074/run.py prepare`
then `python -B tools/dbus-reply-state-074/run.py session-io-safe` in a fresh
approved context. Do not erase receipts to rerun. The checked-in fixed context is
already consumed; changing it requires a separately reviewed attempt, not a retry.
