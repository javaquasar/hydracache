# Cover Prompt: 005 - Typed Query Caching in Rust

Create a 16:9 editorial technology cover image for an article titled "Typed Query Caching in Rust".

Visual direction:

- clean, polished infrastructure-engineering editorial style;
- no readable text, no logos, no mascots, no UI screenshots;
- show a database/query-result source passing through a typed Rust-shaped boundary into a local cache runtime;
- show structured cache-key dimensions as small distinct tiles or segmented blocks;
- show invalidation tags as attached handles or linked tag-like objects;
- imply that the database adapter remains visible and explicit, not hidden behind magic automation;
- imply typed query result caching without implying automatic SQL parsing, table dependency inference, or ORM replacement;
- keep the scene calm, precise, and trustworthy;
- color palette should align with the HydraCache article series: graphite, deep teal, muted copper, warm amber highlights, and a neutral background;
- crisp lighting, high contrast, professional Medium/LinkedIn article cover composition;
- leave enough calm negative space for platform cropping.

Avoid:

- readable words or pseudo-text;
- literal Rust logos;
- brand logos;
- database vendor logos;
- cluttered dashboards;
- terminal/code screenshots;
- cartoon characters;
- cyberpunk overload;
- magical automation imagery;
- heavy replication beams that imply value replication.
