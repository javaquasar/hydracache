# Cover Prompt: 003 - TTL Is Not Enough

Create a 16:9 editorial technology cover image for an article titled "TTL Is Not Enough".

Visual direction:

- clean, polished infrastructure-engineering editorial style;
- no readable text, no logos, no mascots, no UI screenshots;
- show a cache/runtime core with a simple clock or timer motif that is clearly insufficient on its own;
- include additional semantic signals around it: tag-like links, invalidation pulses, refresh paths, and bounded stale windows;
- the composition should imply that time-based expiry is only one input into a broader cache policy;
- show a protected application/cache layer between request streams and a database/service dependency;
- keep the scene calm and precise, not alarmist;
- color palette should align with the HydraCache article series: graphite, deep teal, muted copper, warm amber highlights;
- crisp lighting, high contrast, professional Medium/LinkedIn article cover composition;
- leave enough calm negative space for platform cropping.

Avoid:

- readable words or pseudo-text;
- literal Rust logos;
- brand logos;
- cluttered dashboards;
- cartoon characters;
- cyberpunk overload;
- alarmist disaster imagery;
- hourglass cliches as the dominant subject.
