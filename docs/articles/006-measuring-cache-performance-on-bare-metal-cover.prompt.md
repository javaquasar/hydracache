# Cover Prompt: 006 - How to Measure Cache Performance Without Measuring Noise

Create a 16:9 editorial technology cover image for an article titled
"How to Measure Cache Performance Without Measuring Noise".

Visual direction:

- clean, polished infrastructure-engineering editorial style consistent with the HydraCache article
  series;
- use an isometric cutaway bare-metal server test bench on a calm, warm-neutral studio surface;
- place a dark-graphite and deep-teal cache/processor core inside a transparent isolated measurement
  enclosure;
- route storage, network, interrupt, build, and telemetry activity around that enclosure on a
  separate outer housekeeping circuit;
- show five identical sample modules, alternating teal and muted-copper comparison paths, and sealed
  evidence/archive objects downstream;
- use tactile machined metal and glass, crisp controlled studio lighting, and warm amber highlights;
- communicate isolation, repeatability, controlled comparison, and preserved evidence through
  visual structure only;
- keep the composition readable at thumbnail size and leave safe margins for Medium cropping;
- output at 1672 by 941 pixels.

Avoid:

- readable words, letters, numbers, pseudo-text, labels, logos, or watermarks;
- brand marks, mascots, people, user-interface screenshots, labelled charts, or literal code;
- cluttered dashboards, neon cyberpunk styling, or physically implausible paths.

The final generation used one cleanup pass to remove residual pseudo-labels while preserving the
composition, object count, lighting, materials, perspective, and color system.
