# Cover Prompt: 002 - Single-flight Is Not an Optimization

Create a 16:9 editorial technology cover image for an article titled "Single-flight Is Not an Optimization".

Visual direction:

- clean, polished infrastructure-engineering editorial style;
- no readable text, no logos, no mascots, no UI screenshots;
- show many incoming request streams converging into one coordinated in-flight loader path;
- the central motif should imply one shared load protecting a backend database from a request stampede;
- include a local cache/runtime core close to the application, with a single glowing loader channel and many dimmer joined request paths;
- background should include a subtle database/service dependency that looks protected rather than overwhelmed;
- visual motifs may suggest waiting callers, coalescing, duplicate suppression, and tail-latency stabilization, but without labels;
- color palette should align with the first HydraCache article: graphite, deep teal, muted copper, warm amber highlights;
- crisp lighting, high contrast, professional Medium/LinkedIn article cover composition;
- leave enough calm negative space for platform cropping.

Avoid:

- readable words or pseudo-text;
- literal Rust logos;
- brand logos;
- cluttered dashboards;
- cartoon characters;
- cyberpunk overload;
- alarmist disaster imagery.
