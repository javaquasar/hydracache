# Initial Reserved publication under the original fence

The fixed-only library publisher consumes the original empty reservation fence
and exclusively borrows original fixed authority and signed intent. Baseline
is `d7b46bbb44f0ed1231b238fc361594bb5806f662`. The source lock is never
unlocked and reacquired during publication. There is no fixture-authority
publisher, server entry, installer change or worker execution conversion.

Require a valid initial Reserved state with revision one and completed cell zero,
matching the complete original intent pins before mutation. An unbound mismatch
does not revoke healthy inputs. Already refused inputs cross-latch without I/O.
Before creation use the existing five-step original empty-fence/intent join.

Create only `active-diagnostic.json`, descriptor-relative to the original fixed
leaf, with O_CREAT, O_EXCL, no-follow, nonblocking, close-on-exec and mode 0600.
Never truncate or replace a named object. Reuse the existing canonical schema-one
state envelope. Creation is intentionally visible before the body is complete:
the existing campaign admission refuses every fixed-leaf entry, including an
empty or partial state. This is not a new atomic replacement/recovery protocol.

Retain the created descriptor. Require the original owner, group, device, one
link and exact private mode before writing. Write canonical bytes, sync the file,
sync the retained directory, then verify the original descriptor against its
named inode and exact canonical bytes. Check original ancestry/common fence,
all legacy contexts and an independently opened complete fixed-leaf inventory
at every publication boundary. All other entries refuse. Interleave original
authority/intent revalidation before and after creation, write, sync and binding.
Acknowledge only after the complete post-publication bracket succeeds.

Success owns both the original common fence and exact created document, while
retaining the exclusive original intent borrow. Revalidation checks the published
state and intent under that same fence. Drop releases only the owned lock; it
does not remove state. Publication error owns the same original fence until
the error is dropped. Bound failure latches storage and original authority.
Use the independently exact-safe authority bridge for Policy refusal, retaining
the first failure and acknowledgement uncertainty; do not duplicate intent refusal.

Every created or partially written record remains on failure, including failure
after sync but before acknowledgement. Never adopt an existing record, repair
permissions, remove debris or automatically retry. Fresh empty-fence acquisition
refuses retained context. Read-only historical state inspection is not publication
acknowledgement and cannot resume a worker. Recovery/consumption publication needs
a separate contract; a restart cannot recreate the runtime acknowledgement.

Private nonroot fixtures test exclusive creation, exact inode retention, every
logical partial-publication checkpoint, signed-intent drift, late context,
unsafe/advanced original authority, post-publication substitution, sticky
refusal and independent concurrency. Logical injected failures model interruption
boundaries; they are not machine power-loss or physical-host durability evidence.
Retain baseline, absent API red, repeated targeted tests, Linux/Windows regression,
compile-fail/current/MSRV/lint/format/docs and unchanged qualification/ship refusal.

Peer and clock remain external assertions. Trusted ownership enrollment,
coordinated binary rollout, authenticated peer/time, consumption publication,
original output/start/watchdog/owned cleanup and a reviewed host rehearsal remain
before production activation. All frozen qualification inputs stay unchanged.
