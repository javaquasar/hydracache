  values may be filled in after observation; no threshold is tuned to pass.

  separate allocation lane. Windows requested-live plus working set is not a
  substitute. The completed diagnostic lane must not be promoted into A/B proof.
- Bind source, lock, features, toolchain and binaries before first execution;
  retain every failure and stop on invalid/noisy observations without retry.
- Obtain feature-on exact-SHA hosted semantic receipts; these are not full
  workspace/release gates and cannot themselves accept a performance candidate.
