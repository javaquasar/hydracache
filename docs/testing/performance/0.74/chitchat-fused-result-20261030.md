## What was implemented

borrowed str/ChitchatId/DeltaOp projections lend existing UTF-8 fields and small
scalar headers; public Serializable/Deserializable and their bytes are unchanged.
Generic append remains. Only ambiguous admission uses bounded stack simulation,
existing compressed scratch and a checkpoint that restores original pending/output,
scratch and cache on refusal/unwind. Accepted encoded prefix is consumed once;
compressed tail is kept in existing scratch and consumed by finish. No new Vec,
unsafe stack Vec, global arena, heap pre-reservation or larger thread stack.

The complete nonzero u16 block/item domain was audited before implementation.
MTU remains arbitrary usize, with its original minimum. Independent exhaustion of
all65,535 thresholds gives a262,146-byte workspace envelope, including raw block,
old scratch backup and encoded transaction. Six non-inlined size instantiations
avoid reserving that maximum for small calls. This proves a bound, **not** acceptable
stack/RSS. Original budgets, cases, seed, CPU1.03 and zero-increase contracts stay.
