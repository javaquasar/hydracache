The local publication budget fails before any Starting write. Twelve fresh
original chains request nineteen unchanged checks after real consent admission:
two checks for each of nine future publication boundaries and one final check.
All chains expire. The observation fixture passes because it records refusal,
checks unchanged retained bytes/inventory, verifies sticky refusal and Busy fence
ownership, and verifies fresh-context refusal after drop. It does not pass a
publication gate.

## Owner attribution

A distinct manual diagnostic constructs three fresh original input chains and
checks four original owners three times each on both compilers. All 72 owner
observations remain healthy and mutate no intent. IPC authentication/signature
counts are 0 for kernel-worker, 1 for signed-controller, 2 for reviewed-build
and 4 for OIDC-controller per check. The first current dev budget sample's
single refusing consent check performed 264 IPC authentications.

Reported wall and current-thread user/system CPU are inclusive observations,
not exclusive per-leaf costs. Do not add the owner durations. The CPU counters
show coarse quantization, including zero deltas and deltas larger than a short
wall interval; they do not provide nanosecond CPU accounting. IPC signature spans
cover only those signatures, not every crypto primitive. No signature-cache
optimization or exclusive kernel-cost attribution is established.
