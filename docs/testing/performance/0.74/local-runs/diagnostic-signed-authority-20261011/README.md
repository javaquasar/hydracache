This packet is local runtime safety evidence, not production enrollment, cache
performance, a release receipt or start/restart permission. The
[design](../../diagnostic-signed-authority-local-design.md) defines its boundary.
Preregistration is `3813e614`; implementation is `c130b325`. The final manifest
binds full Git source/tree identities and exact closed log bytes.
There are 37 retained raw captures; 191 local Markdown file targets were checked.

The guard exclusively borrows its original signed-task reader and typed journal.
Only safe storage matching the original checked pins receives refusal. Successful
publication survives reopen; unsafe/foreign storage is not repaired. Unacknowledged
publication stops continuation and is never retried. This does not solve a crash
before publication or make an in-memory unsafe-storage refusal durable.
