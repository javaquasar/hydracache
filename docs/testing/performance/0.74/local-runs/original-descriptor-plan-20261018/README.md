## Ownership hypothesis and isolated implementation

The prior custody owner still needs a complete descriptor inventory before any
barred transfer. Its original sinks are O_RDWR, whereas the generic private
guardian requires O_WRONLY. Relaxing that generic check would not authenticate
the original objects. The new plan therefore borrows the exact original owner
and records ten descriptors: custody, selected alarm, two readers, two sinks,
two original pipe writers and two unsent-message writer aliases.

The initial guardian allowlist has six descriptors: custody, original alarm,
readers and sinks. Its future production collector must inherit only readers
and sinks, and the guardian must shed its sink aliases before opening the
collector barrier. All four original pipe/message writers are excluded from
both role lists. Exact numbers, identities, metadata, flags and sink positions
are recorded; duplicate or negative descriptors refuse. No external constructor,
path, PID, time, key, arbitrary File or replacement alarm is accepted.

Draft capture is followed by the unchanged complete custodied validation and
an exact metadata comparison, then the existing final deadline probe. Later
plan revalidation repeats that complete frame and close, not cached authority.
Each checked plan/revalidation expects 34 authentications and signatures. Those
are reference-call invariants, not performance claims. The only custody accessor
is crate-private and borrowed, checks the same acknowledged storage and never
clones or extracts its File. The plan has no public extraction, send, start,
write, custody release or completion capability.

The registered [plan](../../diagnostic-original-descriptor-plan-20261018.md)
separates this preparation from actual process/cgroup enrollment. A copied raw
FD number is not transferable authority; the private Rust plan's lifetime
remains tied to an exclusive borrow of the original owner.

The holder uses only the checked original role lists. All descriptor/socket
allocation and sorting occurs before raw fork, with inherited signal handlers
