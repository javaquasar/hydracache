## Evidence boundary

native exit immediately without a pipeline. Build/lint/source checks finish
before the serial cost probes. Attribution and allocation instrumentation do
not become healthy functional gates. Full unprofiled local matrices retain
original case order, unset case/cost overrides and permit no retry or splicing.

`facts.ps1` derives scalar allocation pairs, boundary ranges and full matrix
results from raw logs. Verification requires all prescribed selections, original
bundle/qualification and four preceding sealed inventories; it rejects drift,
missing/extra/unsafe/reparse inventory members and summary mutations. A seal
cannot be bypassed through review mode. Initial failures and earlier native/WSL
refusals stay retained rather than being replaced by newer local passes.

No server access, product workload, clock/time-service operation, installation or
