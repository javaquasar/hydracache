## What the combined matrix proves

Both compilers pass all seven cases: normal consuming retirement, one guardian
killed, one guardian stopped, outside writer alias, trust-file drift, duplicate
enrollment and original expiry. The GNU screen also passes. Each attempt uses
actual fixed read-only manager checks, the original owned message/frame, actual
kernel controller credentials from UID/GID 65534, numeric-root ancestry, pinned
cgroup2 and two actual independent root guardians.

Three live `/bin/cat` writers produce readiness bytes through the original
streams. They occupy direct and nested groups, with a third using duplicated
stdout/stderr roles. Real pidfds and `/proc` membership are checked before faults.
Acceptance requires actual SIGKILL waits, empty subtree, original collectors
cancelled/reaped, drained stdout/stderr EOF and independently busy original fence.
Expiry is observed at the captured original deadline without refreshing it.
An outside alias still writes seven bytes and prevents EOF until it is closed.
This is deliberately not proof that cgroups revoke arbitrary external FDs.

The external owning subreaper is separate from Rust Drop. A preparing capsule
inventories only fresh root scopes and cgroup identities for safe cleanup; a ready
capsule exports original readers and exact child pidfds, plus held dummy stdin
writers. Keeping stdin open excludes natural EOF exit as an explanation of writer
termination. The outside-alias negative adds only an intentional stdout writer.
The carrier is private, credential-checked, versioned in `docs/COMPAT.md` and not a
production reader, replay channel or authorization source.

guardian stall and outside alias. Acceptance requires the three writers' exact
SIGKILL waits before the unchanged original deadline. Original collector and
custodian must shed output roles while retaining only fence/timer/socket, and EOF

and lost-ACK matrices remain separate evidence, not silently extended to this new
combined return boundary. The final GNU screen and six-case matrix pass. MSRV
passes owner loss and first-guardian loss, then refuses the next case before

remain absent. The verifier requires this exact partial outcome and refuses to
