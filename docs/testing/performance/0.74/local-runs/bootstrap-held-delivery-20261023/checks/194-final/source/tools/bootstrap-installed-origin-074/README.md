Run check.py for host, 194, 188 and metadata. Host and metadata must run
sequentially on Windows. Each lane retains exclusive logs and exact source;
corrected non-live checks can use -final without overwriting first outcomes.
Tests use private temporary roots and numeric fixture owners, never the fixed
production path or an original live owner. Older child assertion/image modes
remain unchanged and still refuse authority. No installation or unit starts.

The wrapper consumes the same original BootstrapOwnedUnit, repeats unchanged
complete frames around fixed-origin inspection and retires that owner before
added FDs close. Root-owned executable ancestry and same build/hash are separate
from the sealed reference. Parent-local 32-FD/16-role census is not a child map.
Runtime-only binding adds no key, descriptor/owner export, child protocol v2,
credentials/namespaces, release or all-writer proof.

After green stable lanes and a source commit, retain.py --checked-commit SHA
verifies command/source/log/count/qualification identities and creates an
exclusive packet. It never reexecutes tests or reseals evidence. --lanes selects
one accepted lane of each scope. The unsigned selected build is not a clean
signed deployment receipt. Additional hash/validation cost is unmeasured;
correctness test time does not establish original admission deadline fit.
