lanes have distinct names; no output can be overwritten. Native lanes use the
existing unprivileged WSL caches and run component/helper controls, never live
original-manager attempts, services, namespaces, root, SSH or product workloads.
The original release/clock/service restrictions remain in force.

The logger retains selected-source snapshots, exact argv, exit, stdout/stderr
hashes and the first failure. Component elapsed times are not measurements of
original admission-window fit. A successful owned helper exchange is not
original child enrollment or writer cessation. The new installed entry argument
remains unactivated.

After committing the checked sources and method, retain.py requires that exact
40-character commit and four passing lanes with identical sources. It validates
every command, log and snapshot, checks counts and the frozen qualification
digest, and retains earlier failed lanes without promoting them. Its packet
audit keeps original delivery, child entry, start, cessation and server admission
explicitly false. The absent-component and initial lifetime diagnostics were
observed in the tool transcript only; they are not presented as saved raw logs.
