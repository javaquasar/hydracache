# Autonomous original custody while execution remains barred

This packet separates an autonomous pending custodian from the earlier test
holder. The new private runtime component borrows the original custodied owner
and inherits only its checked fence, the same selected alarm and a private notice
socket. It owns no stream or sink and has no activation, send, detach, release or
completion API in an ordinary build. Collector and authenticated-start enrollment
remain separate work.

## Runtime ownership and kernel boundaries

The child is created with clone3 and only CLONE_PIDFD plus SIGCHLD: no shared
address space/files and no numeric-PID pinning interval or signal fallback.
Inherited handlers are blocked before creation and the exact mask is restored
in the parent. The atomic pidfd owner exists before any fallible post-creation
parent check. After isolation, the raw child uses stack and bounded syscalls only.
The notice vocabulary is separately registered in COMPAT; P means pending only.

The child never reads or rearms the original timer. Actual alarm readiness
emits E and latches retention without busy-polling that readable timer. Peer
loss/unexpected traffic and observation failures retain custody regardless of
notice delivery. There is no disk IO or regular-output writer in the isolated
custodian. Initial descriptor isolation is still a pre-readiness operation, not
a guarantee that arbitrary inherited-descriptor close is nonblocking.

The parent wrapper keeps its exclusive original borrow until its kernel field
has dropped. Cancellation targets only the atomic pidfd and waits for the owned
child; normal controls independently observe terminality through a duplicated
test-only pidfd. Drop is not a successful collector-cessation API and cannot
publish completion. Any future active controller still needs explicit writer-tree
custody, cleanup-failure handling and independent guardian supervision.

non-promotable. Workspace formatting runs through WSL. Inspect fixed host guards

cohort and case completeness, reasons, seeds, full-frame counts, actual units and
