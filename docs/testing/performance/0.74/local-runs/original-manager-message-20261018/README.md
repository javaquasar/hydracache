# Original uniquely addressed message preparation

Status: **withdrawn, not accepted into runtime**. Only the plan and negative
evidence are committed. The implementation remains recoverable in the fourteen
source capsules, not as a production capability or a source-code commit.

The experimental private nonexecuting slice consumed the original live-manager/frame owner
without exposing its connection or writers. The [plan](../../original-manager-message-plan-20261018.md)
preregisters exact original names/body/serial binding, full rounds and deadlines.
The old well-known-addressed message remains intact and unsent. The new payload
owns exactly two extra pinned aliases for those original pipes, closing before
the unchanged original owner can release its custody.

The original signed property validator checks the legacy message. The new
envelope must target the retained unique manager; body bytes and serial must
equal that validated legacy message. Typed write-only CLOEXEC descriptors must
match the original stdout/stderr objects in order and retain their actual FD
numbers. Manager/client binding cannot change on revalidation. Missing or
replaced payloads refuse rather than reconstruct. Any error poisons and retains
the original frame, children, alarms and custody, without retry or extraction.

Every preparation/revalidation uses two unchanged complete live manager rounds,
one before and one after payload checks: 68 authentication and 68 signature
calls, four channel/context checks. The original 300/60/10-second windows, origins
and absolute alarms remain. This is additional correctness work, not a speedup.
