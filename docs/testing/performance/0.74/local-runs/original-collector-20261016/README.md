## What the preflight establishes

The acknowledged original request supplies the retained controller/OIDC/build/
worker/authority/kernel chain and common fence. A new exclusively borrowed
wrapper checks collector bytes with that same original owner. Kernel per-message
UID/primary GID and retained supplementary groups produce the sorted unique peer;
fresh original receiver time supplies freshness. No public peer/time/trust, new
worker guard, descriptor or source replacement is accepted by this composition.

Signed request, nonce, controller and complete window must match the original,
and state identity must match it at revision one/cell zero Reserved. Original
checks surround the new verification. Failure permanently refuses all original
chains, without a durable refusal append or a subsequent I/O retry. Healthy
wrapper drop retains the original attempt's fence and file. The state remains
a supplied signed projection, not a durable Reserved/Starting acknowledgement.
This is neither root preparation nor once-only start admission.

## Test scope and provenance

The old attempt baseline passes 12 tests with its manual process proof ignored.
The API-shape probe then fails with E0599 for bind_collector_requirements; it is
a compile-shape test, not a positive runtime exercise. The first implementation
passes seven focused tests and ten signed mutations. The final source adds an

Synthetic controller/issuer/OIDC statements and private nonroot temporary roots
are combined with actual local kernel message/context observations. The seeded
matrix uses 0x0740c098 for eleven validly signed request/state/window/policy/unit
mutations. Separate tests cover malformed/legacy/over-budget envelopes, original
trust/inventory drift, retained bytes/lock lifetime and two independent original
chains. Kernel peer units cover primary-GID ordering, duplication, empty groups
and an oversized union without truncation. Expected failure of an old window
against receiver time is not evidence of external production time/epoch enrollment.

Each mutation constructs its own disposable original fixture; no rejected
runtime guard is renewed or retried into admission.

Some refusal tests deliberately change/remove and restore their own disposable
fixture files. The runtime itself never performs that repair or adoption. Those
tests establish sticky refusal despite restoration, not unchanged metadata after
an externally injected mutation. Positive and signed-mismatch cases separately
check unchanged original request bytes and the held common lock.

The kernel classifier's intentional caught-unwind trace in kernel-group logs
is a canary, not a newly reproduced original fixture failure. The historical
Kernel(Invalid) remains unexplained. Code checks and tests reuse dependencies and
caches; no clean-tree build, binary reproducibility or signed execution
attestation is asserted. Source commits identify the retained final byte set;
committing those bytes does not retroactively attest an earlier clean checkout.

Historical guard comparisons exclude only the exact new module registrations,
not any old function or predicate. Existing budget/deadline canaries remain.
Their coordinated amendments are in the runtime commit so that the intermediate

the new original-collector boundary gate. Old evidence remains at its historical

## Remaining integration

Final original-input regressions pass 76 tests on each compiler, with one existing
manual test ignored. Both versions separately pass the 30-test byte verifier,
26-test kernel group (one manual ignored), and four compile-fail examples for
the new guard. The complete static suite passes 171 tests. All eight final
Linux/Windows, current/MSRV, check/strict-Clippy lanes pass for supervisor and
xtask with all targets/features and locked offline dependencies. No unexpected
first-refusal trace appears in either original-input group.

The unchanged request write-engine manual regression passes nine actual owned
SIGKILL cases, one uninterrupted control and twenty fresh read-only inspections
on current Rust. It preserves retained bytes and original lock release after
death. There is no new durable mutation in the collector preflight, so this is
not presented as SIGKILL coverage of a new publication or root-start producer.

Workspace formatting, documentation and local non-promotable performance
contracts pass. The automatic gated-test registry remains at 176 with no manual
entry added. Require-ship deliberately refuses because candidate identity and
release qualification are incomplete. All 26 retained captures have their
expected native exit status; only the missing-API red and closed ship gate exit 1.

No output files/pipes, root constructor, lifecycle publication, authenticated
original-start, autonomous watchdog, cgroup revocation or all-writer cessation
is produced. Root ancestry and original durable lifecycle ownership must join
before exclusive construction; a caller-supplied signed state cannot fill that
gap. Production policy/epoch/job/host enrollment, later cells and qualification
remain open. The existing request SIGKILL proof is regression of the unchanged
write engine, not a new write-boundary proof for this read-only API.

The manifest inventories normalized UTF-8/LF command output, source objects and
unchanged inputs. Run `./verify.ps1` to check byte/count consistency. No product,
server, workflow, expensive qualification, full release verification or push is
included; no numerical performance claim follows.
