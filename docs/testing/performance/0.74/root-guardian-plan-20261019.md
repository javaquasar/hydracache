# Independent local cgroup root guardians

Baseline is `037802aa0efc0e87ad847f1f285a0d043148535b`. This is the next local
part of the approved root enrollment topology, inheriting R-3, R-4, R-5, R-7,
R-8 and R-10. Preserve every old runtime body, original full-frame predicate,
46 effect brackets and 300/60/10 absolute origins. No installation, supervisor
operation, original manager send or product workload.

Add a distinct stack-only child for the v2 root protocol. It must never call
the allocator-based request reader after clone. Whitelist only existing fence,
existing timer, actual creator pidfd, private channel and original root parent.
Close other inherited descriptors. Receive three atomic-CLOEXEC directory,
kill and events rights from the exact creator; validate their retained/named
root identities, ownership, access, empty domain and original packet binding.
Retain before emitting a rights-free Armed reply. The parent authenticates that
reply against the exact clone3 child and its live pidfd, never a supplied PID.

Two independent children inherit the same original fence and timer OFDs. Do not
create/read/reset/rearm a timer, reacquire/unlock a fence, renew a bound or infer
completion. The ordinary parent can inspect the actual timer clock and expiry
without consuming it. Consume global uncertainty before the first send, submit
both root requests before waiting for replies, and refuse readiness unless both
actual children acknowledge under the unchanged bound. Partial creation owns
exact-child cleanup before signal-mask restoration can fail. After a possible
enrollment, closing the parent's channel requests revocation, not cancellation
or successful cleanup; an independent child continues holding the fence.

On owner pidfd termination, timer expiry, channel loss, unexpected message or
root drift, enter irreversible revocation. Submit only the originally retained
kill FD, never reopen a replacement target. Keep watching the retained events
object and revoke late population as well. A failed live frame prevents Armed;
after enrollment it cannot erase the previously retained revocation obligation.
Kill submission remains an attempt, not cessation of outside writer aliases.
No child may publish completion or release the fence.

Start with ordinary stack parser/FD cleanup/timer checks and explicit isolated
local-root expiry, peer-loss, late-population, single-child failure, missing ACK
and hidden-writer controls. Keep common-mode failure as an expected negative.
Actual creator SIGKILL and joined original-frame boundaries require their own
subprocess matrix; do not label a closed peer as process death. The local pair
does not construct original admission, a held systemd unit or production trust.

Register the active v2 reply scope and manual gate additively. Retain a red
missing-module check, selected-source GNU/MSRV/Windows results, old root and
guardian regressions, raw-byte evidence, source-contract/fmt/lint/docs/registry
and local non-promotable performance-contract checks. Keep evidence and article
conclusions separate from implementation. The qualification manifest stays
byte-identical.
