# Closed bootstrap image inventory before child entry

Baseline e40d4732 has a signed bootstrap join, but its original census stops at
23 retained descriptors and 11 roles. Host and held launcher remain privately
owned by PinnedRoles, while the bootstrap image is held by BootstrapOwnedUnit.
Before a child protocol can address them, join all three into the same closed
inventory. Do not enable an executable, transfer, remapping or execveat yet.

Keep all old full frames, hashing, root/source/authority checks and 300/60/10
origins and bounds. Add an opaque original-20 contribution from the existing
material descriptor stamps, an opaque image provider under PinnedRoles, and a
value-only extension of CompleteBindings. No FD getter, callback, duplication,
open, clock query or export. All 26 FD numbers must be distinct. Preserve the old
11 roles exactly; append host/launcher/bootstrap semantic roles 11/12/13, not
inherited FD destinations. Require distinct sealed readonly regular images,
CLOEXEC, expected identity/size and stable metadata/offset. Compare the resulting
inventory in the existing bootstrap observation, inside the same three frames.
Failures follow the old wrapper's shared refusal and original retirement path.

First add a current-source red integration gate. Test pure mapping/uniqueness
mutations, actual private memfd flags/seals/identity/offset and provider checks;
old-prefix fixtures are models, not live guardian/original-owner proof. Reuse
the old fault models and source contracts, compile/check/lint GNU 1.94/MSRV 1.88,
check formatting, docs/registry/local contracts and retain exclusive evidence.
No original live fixture, process execution, service/clock change, server or
measurement cohort. Old packets and first failures stay immutable.

This is a runtime-only extension; no old wire/durable schema, public API, policy,
receipt or qualification identity changes. The next boundary is an owned sealed
child-entry binding and fixed authenticated child protocol. Original delivery,
execveat, writer cessation, completion/cells 2–4 and server admission stay closed.
