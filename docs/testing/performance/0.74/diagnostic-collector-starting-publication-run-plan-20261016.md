Baseline `e7513b25` has the accepted frame fault gate and byte codec, but no
durable Starting publisher. The operator authorizes implementation, actual
SIGKILL and lost-ack checks without installation or supervisor interruption.
The existing [publication design](diagnostic-collector-starting-plan-20261016.md)
defines ownership and all nine boundaries; lease/clock/authority windows remain
unchanged. This packet neither introduces output/process execution nor enrolls
the SSH fixture as a trusted production worker.

The candidate consumes only OriginalFramedConsent, encodes its original retained
request/Reserved/consent, enters a private attempted storage phase and performs
nineteen complete live frame checks around nine storage steps and before final
acknowledgement. Exclusive creation uses 0600; seal uses 0400; the original file
and directory are fsynced before acknowledgement. Any error retains the owner,
FD and fence with sticky refusal. No recovery, reset, overwrite or retry exists.
The unchanged default two-file reader must still refuse a third file.

Run clock-free storage/API/protocol/compile-fail checks locally on Rust 1.94 and
1.88, affected check/strict Clippy, formatting and all static/docs/registry/local
contracts. Retain red API and assembly failures separately from final results.
The scope-specific ship guard remains closed; do not invoke qualification.

Run the normal release test binaries on dedicated Linux, serially as the
nonroot SSH UID, with bounded time/output and only registered exact tests:
collector_starting_publication_boundaries_and_live_refusal, then
collector_starting_process_crash_all_stages_and_lost_ack. The first requires nine
independent interruptions, nine original drift cases and one healthy control.
The latter requires three seeded repetitions: SIGKILL at all nine stages and
AfterReturn, one uninterrupted control and two fresh-process inspections for
each history. Seed `0x074057d1` permutes cuts; no failed run is retried into PASS.
This proves process-loss behavior, not power-loss/reboot persistence or injected
storage-device EIO. A complete fsynced file still cannot reconstruct lost runtime
acknowledgement.

Each child builds its own kernel receiver and full original chain after exec;
no live owner is fork-copied. The parent pins the exact child with pidfd and owns
private 0700 temporary fixture directories. Existing authority fixture grammar

are `/tmp/hydracache-collector-starting-crash-*`, with all modeled host paths below
their `origin`. No production directory, account, unit or global lock is mutated.

context and authority across termination and fresh inspections. The common lock
must be Busy while the owner lives, free after death, and fixed-history admission
must remain refused. Legacy raw lock acquisition is not durable replay closure.

The transfer/runner directory is separately owned and isolated. Pin both binary
hashes before dispatch; retain raw logs and observed exits. Read-only pre/post
checks require no active campaign/lifecycle context and unchanged supervisor
PID/start/restarts/boot, installed binary and receipt. Abort on drift; never stop,
restart or install a service. No Actions dispatch, product workload, measurement
