# Separately admitted local WSL clock control

The operator explicitly authorized temporarily stopping and restoring only
systemd-timesyncd inside WSL Ubuntu. Windows services, clock values, WSL settings,
the dedicated server and runtime predicates are outside this control's writes.
The original validation-frame packet keeps all twelve budget chains and its
incomplete Rust 1.94 fault matrix. Do not replace or reinterpret those results.

Use the unchanged candidate working-copy hashes recorded in that packet and
the exact existing normal-release test executables. No rebuild, signature cache,
new origin, widened duration or relaxed predicate belongs to this experiment.
The candidate is not committed while its focused fault gate is incomplete.

One foreground root wrapper must first observe the exact service active, install
an exit/signal restoration trap, stop that service, and verify it inactive. It
must not disable it or change configuration. A ninety-second read-only probe
then samples CLOCK_REALTIME and CLOCK_BOOTTIME every second. Refuse on either
clock reversing or an adjacent realtime/boottime increment difference greater
than 100 milliseconds. This is an additional local environment precondition,
not a replacement production time source or waiver of a kernel clock check.
The foreground wrapper keeps WSL alive; preflight does not guarantee future
clock stability and every original runtime observation remains mandatory.

After the probe, run exactly one complete manual live-drift/reference/concurrent
matrix on Rust 1.94 and one on Rust 1.88, followed by exactly one three-chain,
nineteen-check normal-release budget cohort per compiler. All are nonroot as
the existing artur account, with no product workload or server mutation. Each
command has a fixed 900-second external stop, never an extended admission lease.
Run serially without builds or another experiment. A failed command stops this
cohort, still restores the service and retains its output. Do not rerun failed
samples into a pass; any source or environment correction needs a distinct
explanation/control. Forty mutation pairs plus five old-reference cases and
healthy-order/construction/concurrent controls must all be observed per matrix.

On success or failure, start only the exact previously active timesyncd service
and verify it active. An independent follow-up read checks restoration. Record
wrapper source, observed executable hashes, clock rows, all test output and the
service states in a new packet. These are unsigned local observations, not
installed-source attestation. The earlier WSL failures and all dev negatives
remain; no publication, process-start or server-admission claim follows.

A complete green focused gate permits committing this isolated validation-frame
candidate and continuing durable Starting under its already recorded plan.
Actual exclusive write/seal/fsync/acknowledgement and real SIGKILL/lost-ack tests
must then establish their own result. Original execution, all-writer cessation,
later cells and signed host rehearsal remain separate prerequisites.
