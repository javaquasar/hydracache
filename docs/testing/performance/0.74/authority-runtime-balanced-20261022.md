The fixed descriptive benefit rule requires every block ratio below 0.95 on
both compilers; cost requires every ratio above 1.05 on both. Neither endpoint
passes either rule. Exact squared geometric comparisons preserve boundary ties.
Min/max order-statistic intervals have nominal 99.21875% population-median
coverage only for IID continuous block ratios; a shared WSL host may violate
that assumption. These are not release non-regression intervals, nor proof of
equivalence. Favorable medians do not resolve the uncertainty.

Balanced role position and compiler order therefore did not make this host and
method sufficiently discriminating for the fixed practical boundary. That is
an experiment limitation, not a proven explanation involving frequency,
scheduling, virtualization or a particular runtime operation. The old 28-process
cohort remains immutable and is neither pooled with nor replaced by this one.
