its local implementation, not production enrollment, installation or execution.

## First implementation package

Add a distinct held-build policy, signed receipt, constrained signer and content
verifier under diagnostic_builder. Fixed logical roles map launcher to the new
diagnostic_held_launcher target and watchdog/collector to the existing
hydracache-long-run-supervisor-074 host target. This chooses Cargo target names,
not production installation paths or an ExecStart. Require distinct host/helper
bytes and preserve the old worker receipt, policy, source, locks and signer.

Policy loading requires an independent exact policy digest, expected controller
key and epoch. Reload the legacy worker policy against that same controller and
its independent pin; the new builder key must differ from both keys. The policy
pins exact source/tree/root-lock inputs and a fixed Linux GNU release recipe,
toolchain and empty feature set. A supplied pin/epoch is reviewed configuration
input, not an observed original authority epoch or a live owner capability.

The new domain signs canonical newline-terminated bounded JSON. Receipt policy,
epoch, role mapping, build observations and artifact/log/lock digests must agree.
The signer derives the body from checked observations and bytes; it is not a
general statement-signing API. Require the two exact Cargo binary targets,
package/source/output suffixes, non-test optimized profiles, no features, one
successful final event and no duplicate/missing/foreign binary. Retain raw log
bytes. A signature asserts the isolated build job's observations; ELF/content
inspection does not independently reproduce compilation.

Register both formats and the new domain in COMPAT, with no migration or upgrade
from worker/v1/v2/v3 authority. Return only opaque checked build data with content
and expected-role comparison, never a start/send/arm/release/completion/unlock
method. No filesystem, clock, key generation, subprocess or manager operation
belongs to this module. Real role files, protected signer production, an actual
held launcher and original policy/epoch/frame join remain subsequent packages.
