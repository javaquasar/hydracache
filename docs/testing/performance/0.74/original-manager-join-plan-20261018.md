# Original receiver and manager channel validation join

Baseline is `0feaf9b1` after the separate reply interoperability correction.
Consume the original enrollment frame into a private owner of its fixed live
manager channel. Keep the original frame, child kernels, material/message,
descriptor inventory, validators and absolute bounds unchanged. This join sends
no original message and grants no execution, completion or release capability.

Derive an opaque receiver-context binding from the original retained kernel
packet under that owner. Retain its actual Origin, not a serialized host/name
snapshot. Compare boot and typed user/mount/PID/time nsfs objects to the live
channel's selected view, including a newly retained caller mount pin. Bracket
construction and each comparison with the old sender/origin/hold checks or the
complete original frame as appropriate. Any failed comparison latches refusal.
An independently captured current namespace is not the original receiver proof.

The join opens only the existing fixed channel. It accepts no caller channel,
path, identity, factory or context claim. Its new light observations enclose one
unchanged complete frame revalidation; they neither remove intermediate old
checks nor cache signature/configuration/epoch results. Inspect original children,
inventory, custody and deadline around channel observations and after the closing
frame. Operation caps never extend original admission windows. Preserve Reserved
300 s, Starting 60 s, progress/challenge 10 s, original origins and alarm objects.

Failure owns the entire original frame/channel/context and poisons the original;
there is no retry, reconstruction or getter returning the former owner. Drop
retains the original collector/custodian cancellation order before message,
writers/sinks and final custody. No message/FD/name/connection export, serde,
Clone, arbitrary callback or start route is added to the production interface.

Test shared ordering with a separate test-only channel implementation and the
real nonroot original full-frame fixture. That test channel cannot construct the
production join. Cover healthy controls, unchanged record/origin/bound/FD facts,
trust/message/output/child/context/channel refusal and sticky retry rejection.
Keep test-only factories out of the production constructor. Separately run only
an exact local WSL-root read-only actual fixed-bus/context case, with owned IPC
FDs and no child launch, service operation, filesystem trust enrollment or clock
change; do not call this a full production enrollment. Nonroot fixed-channel
access remains a distinct declared refusal, not a failed positive retried as root.

Use an expected missing-join compile test before implementation, current/MSRV
focused units/fixtures, affected all-target checks/strict Clippy, portable controls,
source-freeze/mutation guards, registry/docs and the local non-promotable contract.
Register exact additive exceptions only; old source bodies must restore exactly.
Stop a selected cohort at the first unexpected result and preserve it without
retry or deadline changes. Retain source/image bindings and a read-only verifier.

This local package does not prove negotiated FD delivery, active systemd start,
all-writer cessation, full active SIGKILL coverage, completion, later cells, real
policy/epoch enrollment or server admission. Installation, supervisor changes,
product workloads and expensive qualification remain outside its scope.
