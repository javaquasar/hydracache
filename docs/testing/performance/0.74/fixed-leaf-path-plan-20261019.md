measured images equal the selected `7c523942` preparation packet. The first
isolated hypothesis removes temporary path construction for fixed proc children
and the four namespace names. No syscall, filesystem check, metadata field,
read, FD close, live observation, effect bracket or deadline may disappear or
move. Unknown namespace names retain the old formatting behavior. No trust or
admission result is cached. Native and embedded product APIs are untouched.

Before implementation retain the baseline GNU retirement result, old images
and an A/A leaf control. Add a test-only exact old leaf reference and pair
actual fresh kernel reads in 15 ABBA blocks of 16,384 iterations per leaf,
rotating all four namespace names. Run three repetitions per compiler, with no
concurrent build or source suite. Preserve raw observations and source/image
identity. Warmup and timing surround only nonexecuting local kernel checks;
timing is not authorization or a product throughput benchmark.

Evaluate 45 paired block ratios per compiler and leaf with a fixed-seed 5,000
resample bootstrap of mean log ratios. Retain only if both leaf point estimates
are positive on each compiler, at least one leaf's 95 percent interval is
strictly positive per compiler, and neither leaf has a statistically confirmed
regression. Otherwise retain the negative result and revert only this candidate.
Do not adjust the rule after seeing the candidate. Source/semantic correctness
and actual GNU retirement acceptance are separate mandatory checks, regardless
of the microbenchmark outcome. Report wall costs, not CPU or allocation claims.

identities, filesystem and inode drift, unchanged boot decoding and errors,

permit only the preregistered substitution and added tests. Keep all previous
