measured images equal the selected `7c523942` preparation packet. The first
isolated hypothesis removes temporary path construction for fixed proc children
and the four namespace names. No syscall, filesystem check, metadata field,
read, FD close, live observation, effect bracket or deadline may disappear or
move. Unknown namespace names retain the old formatting behavior. No trust or
admission result is cached. Native and embedded product APIs are untouched.

Before implementation retain the baseline GNU retirement result, old images
and an A/A leaf control. Add a test-only exact old leaf reference and pair
actual fresh kernel reads in 15 ABBA blocks of 16,384 iterations per leaf,
rotating all four namespace names. Run three repetitions per compiler, with no
concurrent build or source suite. Preserve raw observations and source/image
identity. Warmup and timing surround only nonexecuting local kernel checks;
timing is not authorization or a product throughput benchmark.

Evaluate 45 paired block ratios per compiler and leaf with a fixed-seed 5,000
resample bootstrap of mean log ratios. Retain only if both leaf point estimates
are positive on each compiler, at least one leaf's 95 percent interval is
strictly positive per compiler, and neither leaf has a statistically confirmed
regression. Otherwise retain the negative result and revert only this candidate.
Do not adjust the rule after seeing the candidate. Source/semantic correctness
and actual GNU retirement acceptance are separate mandatory checks, regardless
of the microbenchmark outcome. Report wall costs, not CPU or allocation claims.

Differential tests cover fixed and unknown/NUL namespace paths, kernel
identities, filesystem and inode drift, unchanged boot decoding and errors,

permit only the preregistered substitution and added tests. Keep all previous

Record failures, never retry an unfinished attempt. Only local WSL fixtures and

## Calibration correction before any candidate

The first A/A series at `bde39e34` reports GNU boot +4.55 percent with a
95-percent interval above zero for identical source bodies; MSRV does not pass
the adoption rule. This cannot establish a path optimization. Keep those raw
controls. Before implementing any candidate, use the same opaque function-pointer
caller loop for both bodies and a balanced ABBA followed by BAAB inside each
block. Iterations, 15 blocks, three repetitions, 45 ratios, bootstrap seed and
the adoption rule are unchanged; each block now averages four timings per body.
Perform one new complete A/A series with this v2 harness. If significant A/A
bias persists, do not adopt this small-effect candidate from these measurements.
This is a local measurement correction, not a change to any admission clock,
qualification workload or release threshold.

The v2 source-equivalent comparison still reports GNU namespace +3.38 percent
with interval above zero, without a production substitution. It is not a valid
counterfactual for a small path change; code generation and environmental noise
have not been separated. Do not use either within-image series for adoption.
The final v3 control compares the actual same leaf entry between executable
images using an external ABBA/BAAB crossover. First use byte-identical images
for one full A/A calibration. Only if its intervals contain zero on both leaves
and compilers, implement the fixed-path candidate and compare the retained
baseline image with it. Keep iterations, blocks, repetitions, bootstrap and
adoption rule unchanged. Each subprocess reports only its internal leaf loop;
launch/setup time is excluded and retained stdout proves the selected test.

comparison is promoted and none of the estimator, repetitions, iterations or
acceptance thresholds is changed. Earlier false positive controls remain raw
