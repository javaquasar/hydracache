command, same-volume upgrade and rollback, and three-node Raft checks
on AX42. Its sources passed all 24 quota and six durable-storage cases.

## Performance programme

The six-hour maintenance result covers a single signed build at 250 mTLS
SET/GET pairs per second on one connection. The paired W11 performance
qualification remains open and is deferred beyond this binary maintenance
release. The last clean A/A calibration passed three of five pairs at the
3% threshold. The comparison has zero qualifying I74/C74 pairs.

To resume W11, pass five clean A/A pairs with the existing guards and
qualify five pairs of the exact signed I74/C74 builds. The same roles
then need the six-hour qualification and a separately authorized
24-hour confirmation under the registered workload.

## Activation and rollback

Upgrading a server requires replacing the binary and restarting its service
through the normal deployment procedure. The exact RC passed the recorded
same-volume and three-node upgrade and rollback checks against 0.73.
The signed stable binary separately passed same-volume member and three-node
rolling upgrade and rollback checks against the published 0.73 binary.
W11 tooling is provisioned independently and uses its original lifecycle
and process-identity checks.

## Registry publication

Crates.io publication remains open. On Rust 1.88, the registry SQLx 0.8
SQLite driver and the pinned Diesel SQLite binding resolve to conflicting
`libsqlite3-sys` versions. The registry Raft and sled dependency graphs
also fail the advisory policy without exceptions.

Before enabling registry publication, verify that the published
dependencies resolve and build together in a clean Rust 1.88 consumer
workspace. Run the advisory checks without exceptions and confirm Cargo
packaging and the publication dry run for the package graph in dependency
order. The release manifest remains `planned` and the registry workflow
requires `shipped` before publishing. Changes to the released source or
dependency declarations require a separately verified patch release with
its own tag and evidence.
